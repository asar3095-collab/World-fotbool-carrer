# World Football Career

Мобильный браузерный прототип футбольной карьерной игры.

## GitHub Pages
1. Откройте Settings → Pages.
2. В Build and deployment выберите Deploy from a branch.
3. Branch: main, folder: /(root), Save.
4. Сайт появится по адресу https://asar3095-collab.github.io/World-fotbool-carrer/ после публикации.

Прогресс текущего прототипа сохраняется в localStorage браузера. Полная база всех стран, клубов, игроков и турниров будет добавляться постепенно.
